# Julia's website

Julia's personal internet archive, including her bio, projects, investment portfolio, side quests, reading list, images, and videos.

## Main folders

- `app/` contains the pages, content, components, and styling.
- `public/media/` contains the images and videos used throughout the site.
- `.openai/hosting.json` connects this project to its existing published Sites URL.
- `tests/` contains the site checks.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Validate changes

```bash
npm run build
```
